# HHmail 1.0.0

本地优先的学校邮箱客户端 + AI 助手：用微软账号登录学校邮箱（Microsoft 365 / Outlook），
**只读收信（不改动服务端邮件）+ 发信（回复/转发/新写/草稿）** + AI 摘要 + AI 检索问答 + 自动标签 / 彩色类别。
不绑定任何一所学校 —— 显示名称、标签词表、AI 服务商、类别都能自己改。
邮件、摘要、索引、对话全部保存在本机；只有调用 AI 时才把相关邮件内容发给你自己配置的服务商。

## 下载

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| Windows 10/11（x64） | `HHmail-Setup-1.0.0.exe` | 安装版（可选安装目录、生成快捷方式） |
| Windows 10/11（x64） | `HHmail-1.0.0.exe` | 免安装便携版（可放 U 盘；数据仍在本机） |
| macOS（Apple 芯片 M 系列） | `HHmail-1.0.0-arm64.dmg` | 拖进「应用程序」即可；同名 `.zip` 为免安装版 |
| macOS（Intel） | `HHmail-1.0.0-x64.dmg` | 需要时自行打包：`npm run pack:mac -- --x64` |

校验：下载后可用 `SHA256SUMS.txt` 核对完整性（见文末）。

## 安装（Windows）
1. 双击 `HHmail-Setup-1.0.0.exe`，按向导下一步（可改安装目录，可只装给当前用户）；
2. 首次启动 → 「开始登录」→ 浏览器里用**学校微软账号**登录 → 回到应用会自动开始同步；
3. 便携版直接双击 `HHmail-1.0.0.exe` 即可，不需要安装。

## 安装（macOS）
1. 双击 `HHmail-1.0.0-arm64.dmg`，把 **HHmail** 拖进「应用程序」（或解压 `.zip` 得到 `HHmail.app`）；
2. 首次打开会被 Gatekeeper 拦下（本版本为 **ad-hoc 签名、未公证**），任选一种放行：
   - 「应用程序」里 **右键点 HHmail → 打开 → 再点「打开」**；
   - 或终端执行：`sudo xattr -dr com.apple.quarantine "/Applications/HHmail.app"`；
   - 或「系统设置 → 隐私与安全性」→ 找到被阻止的 HHmail → **仍要打开**；
3. 打开后需要**重新登录一次**（登录态与数据按机器本地保存，不会跨设备同步）。

## 这个版本有什么
- **只读收信**：IMAP + OAuth 设备码登录，多文件夹（`SELECT` readonly、正文 `BODY.PEEK`，不动服务端状态）；本地 SQLite + FTS5 全文检索
- **AI 摘要（决策卡）**：主旨 / 关键信息 / 截止与行动项 / 分类 / 可信度
- **AI 助手**：聊天式多轮问答，回答带可点击引用（点邮件名跳回原文）
- **检索索引卡片**：类型 / 课程号 / 截止 / 别名，支撑中英 + 简繁跨语言检索
- **知识库**：本周简报 + 按课程/类型自动归集的集合档案卡
- **自动标签**：规则 + AI 主题标签（词表可改、可挑示例邮件当参考）+ 手动标签（不被重算覆盖）
- **彩色类别**：一封邮件一个类别，列表用对应颜色标出；红旗 / 星标 / 稍后提醒 / 自定义视图 / 批量操作
- **发信**：回复 / 转发 / 新写 / 草稿；学校账号 SMTP + XOAUTH2（登录时勾选 `SMTP.Send`），或改用个人邮箱 SMTP；本地「已发送」记录
- **多 AI 服务商**：DeepSeek / 阿里云百炼 / Kimi / 智谱 GLM / OpenAI / 自定义 OpenAI 兼容地址（如本地 Ollama）

## 系统要求
- Windows 10/11 x64，或 macOS 11+（Apple 芯片 / Intel）
- 需要能访问你所在学校的 Microsoft 365 登录页；使用 AI 功能时需要能访问你所选服务商的 API

## 隐私
- 不内置任何 API Key / 密码 / 令牌；密钥经系统安全存储加密（Windows DPAPI / macOS Keychain）
- 邮件正文、摘要、索引、对话只存在本机数据库；卸载应用不会上传任何数据
- 远程图片默认不加载（防跟踪像素）

## 已知限制
- macOS 版未做 Apple 签名与公证，首次打开需手动放行（见上）
- 暂不支持自动更新：升级请下载新版本覆盖安装，数据会保留
- AI 摘要/问答需要你自己配置服务商的 API Key（应用不代付、不内置）

【这是什么】
HHmail —— 学校邮箱（Microsoft 365）客户端 + AI 助手。
· 收信：只读同步多个文件夹（不会删除/移动邮件，也不会把邮件标记为服务端已读）；
· 发信：回复 / 转发 / 新写 / 草稿发送（学校账号走 SMTP + XOAUTH2，或改用个人邮箱 SMTP）；
· AI：自动总结（决策卡）、搜索问答（问收件箱）、检索索引、知识库集合；
· 效率：自动标签、彩色类别、红旗/星标、稍后提醒、自定义视图、批量操作、快捷键；
· 本地优先：邮件、摘要、索引、对话都保存在本机数据库。

【v1.0.0 性能专项：彻底解决「邮件一多就卡」（实测）】
· 真因：数据库里每封邮件的 HTML 正文平均 445KB（最大 11.6MB），而列表查询会把 **200 封的整份正文（约 106MB）**
  读进内存再传输 —— 实测一次列表查询要 **3270 毫秒**。
· 修复：① 列表查询只取列表需要的字段；② 正文搬到独立表（打开邮件时才读），数据库一次性整理；
  ③ 列表超过 60 行才启用「只渲染可见行」；④ 同步进度/新邮件事件合并刷新，不再把整个列表反复重画。
· 效果：同一条列表查询 **3270ms → 1.5ms**，IPC 数据量 **106MB → 99KB**；3000 封邮件下切换页面 20–90 毫秒。

【v1.0.0 新增：自动标签（A 规则 + B AI 主题标签 + 示例邮件）】
· 🏷 自动标签：每封邮件会自动带上标签，列表里直接显示；点标签就只看这一类邮件（只是筛选，不会删改任何东西）。
  - A 规则标签（零成本、可随时重算）：类型（作业/考试/选课/行政/活动/奖学金/通知/广告）、课程号（如 ENG1110B）、
    平台（Blackboard / Gradescope / CUSIS / Zoom…）、截止状态（紧急 / 有截止 / 已过期）。
  - B AI 主题标签：生成摘要时顺带产出（不额外收费、不多一次调用），从词表里挑 1-3 个，例如
    实习、招聘、讲座、社团、志愿活动、宿舍住宿、缴费、IT 服务、心理支援…
· 📝 示例邮件（few-shot）：在邮件详情页点「🏷 设为 AI 标签示例」，勾选这封邮件应有的标签，
  之后 AI 打标签会照这个口径来；示例只保存「主题 + 标签」，不保存正文。
· ⚙️ 设置 → AI 总结与问答：自动标签开关、标签词表（可改成你自己的分类）、已打标签统计、
  「按索引卡片重算规则标签」按钮、示例邮件列表（可移除）。
· 🔒 自动标签只用于浏览与筛选，不参与删除或任何破坏性操作；误标可以「重算」或改词表后重跑。

【安装（二选一）】
方式 A（推荐）：双击「HHmail-Setup-1.0.0.exe」按向导安装，
                完成后从开始菜单/桌面快捷方式启动。
方式 B：双击「HHmail-1.0.0.exe」直接运行（免安装便携版，
         可放 U 盘；数据保存在本机 %APPDATA%\mail-ai-assistant）。
说明：从更早的旧版本升级时，首次启动会自动把旧数据目录
      （%APPDATA%\legacy-mail-app）里的邮件库/设置/登录态复制过来，无需重新登录。

【首次启动的两条 Windows 提示】
1. SmartScreen「Windows 已保护你的电脑」：本软件未做商业代码签名，
   点击「更多信息」→「仍要运行」即可。
2. 防火墙弹窗：勾选「专用网络」→「允许访问」（联网登录与同步需要）。

【登录（第一次使用，约 2 分钟）】
1. 打开应用 → 点「开始登录（设备码）」→ 记下设备码。
2. 点「打开验证页面」→ 浏览器自动打开微软登录页 → 输入设备码。
3. 用你的学校账号（Microsoft 365 / Outlook）登录；如学校要求二次验证（DUO 等），按手机提示完成。
4. 浏览器出现「You have signed in…」后回到应用，自动进入收件箱并
   开始同步全部历史邮件（首次较慢，进度在顶栏显示）。

【日常使用】
· 收件箱：左侧列表（发件人/主题/时间），点开看正文；点过的未读邮件
  自动变为已读（仅本机状态，不影响服务器）。
· 搜索：顶栏搜索框支持主题/正文/发件人（中文英文均可）。
· 同步：顶栏「↻ 同步」手动刷新；设置里可配置自动刷新间隔
 （默认 5 分钟）。以后每次只拉新邮件，很快。
· 收不到新邮件 / 少邮件：设置 →「🔧 修复同步（重新拉取缺失邮件）」。
· 托盘：点窗口 ✕ 不会退出，而是缩到右下角托盘后台运行；
  左键托盘图标恢复窗口，右键可「显示主窗口 / 退出应用」。
· 登录过期：凭据过期且无法自动续期时，应用会回到登录页提示重新
  登录（本地已同步的邮件不会丢失）。

【AI 功能（可选）】
1. 左下角「设置」→ 粘贴 DeepSeek API Key（https://platform.deepseek.com
   获取，sk- 开头；保存在本机并经 Windows DPAPI 加密）。
2. 模型默认 deepseek-flash（V4.1 Flash，快且便宜）；也可切到 deepseek-v4-pro。
   总结提示词可自定义，默认已针对「学生 + 过滤广告」调优。
3. 打开任意邮件 → 「✨ AI 总结」→ 生成「决策卡」摘要：第一眼是顶部的
   「最近截止 + 倒计时」（如「09-13 23:59　还有 2 天」，越快越红），
   接着是一句话主旨、行动项清单（带截止徽标）、紧凑的关键信息行与分类标签；
   长内容默认裁断，点「展开全部」看完整内容，点「源码」看原始文本。
   旧摘要（写成一大段、看不清重点）在设置里点「🔁 重新生成全部摘要（覆盖旧的）」
   即可按新模板重跑。
4. 设置里打开「新邮件自动 AI 总结 + Windows 通知」后，来新邮件会
   自动总结并弹系统通知，点通知直接打开该邮件。
5. 只想给还没有摘要的邮件补摘要：设置 →「🧠 总结所有未生成摘要的邮件」。
6. AI 助手页是聊天式的（像常见 AI 客户端）：左栏是对话列表，点「＋ 新建对话」开新话题，
   每个话题会记住上下文（「那截止呢？」这类追问能接上上一轮）；右侧是与助手的消息流，
   回答默认渲染成 Markdown（可切「源码」看原文），下方是引用邮件，点一下跳回收件箱原文。
   Enter 发送、Shift+Enter 换行。
7. 助手不会拿邮件硬凑答案：问「你能做什么 / 能不能查知识库」这类问题会直接说明能力边界
   （只读本地已同步邮件、不联网、不发信、不编造），只有真的在问邮件内容时才去检索，
   检索不到会如实说「未找到」。
8. AI 助手的检索用的是另一份「检索索引卡片」（与给人看的摘要分开存，
   含类型/课程号/截止时间/别名与可能被问的问题）。它会在上面点「重新生成全部摘要」
   时一并建立（设置页可看到「检索索引：已建 x/y 封」）；旧邮件不重跑的话，AI 助手只能靠原文检索。
9. 检索同时认「中英」和「简繁」：中文问「图书馆／学费／宿舍／实习」，能命中英文主题的
   Library / Fees / Hostel / Internship；简体问「选课」，也能命中繁體「選課」。
   回答里最相关的那封邮件会排在第一（20 题离线评测：第一条就命中 100%、集合题覆盖率 100%）。
   汇总类邮件（Daily Notifications、Weekly Highlights）不会抢占第一位。

【知识库（侧边栏 📚）】
· 本周简报：这周收到多少封、本周截止清单（按时间排序 + 剩余时间）、类型分布与涉及课程——
  全部是本地聚合，不调用大模型，所以不会编造。
· 课程集合 / 类型集合：由 AI 检索索引卡片里的 COURSE / TYPE 字段自动派生；
  一封邮件可同时属于多个集合（多标签）。点进去是「档案卡」：共多少封、最近截止（带倒计时）、
  涉及的系统或平台（如 GraderScope、Blackboard），下面是该集合的邮件列表。
· 归类不对可以点「移出」修正（本地修正，重新生成该邮件索引卡片后恢复）；
  集合只用于浏览与汇总，不会硬性过滤 AI 助手的检索。

【发信：为什么 Outlook 能发、现在这台也能了】
· Outlook 能发是因为它走 MAPI/HTTP、EWS、Graph 这条通道（微软一方应用、租户默认信任），
  跟 SMTP AUTH 无关；本客户端用的是 IMAP + SMTP AUTH，需要单独的发信权限。
· 实测结论：微软 365 的学校租户大多允许本客户端申请 `SMTP.Send`，且邮箱允许 SMTP AUTH
  （AUTH XOAUTH2 返回 235 Authentication successful），此时学校账号即可发信。
· 用法：设置 → 发信 → 确认「发信权限（SMTP.Send）」已勾选 →
  点「🔑 退出并重新登录」→ 用设备码登录，授权页会多一条「代表你发送邮件」，同意即可 →
  回来点「✉️ 用学校账号发测试邮件给自己」，收到邮件就说明发信链路完全打通。
· 若失败，先点「发送能力自检」看服务器原文：`535 5.7.139 … SmtpClientAuthentication is
  disabled for the Tenant` = 学校关闭了 SMTP AUTH（只能改用 Graph Mail.Send，需管理员同意）；
  其它 535 = 登录 scope 里没有 SMTP.Send（重新登录并在授权页同意即可）。
· 不想给发信权限：把「发信权限」取消勾选并重新登录，即回到纯只读。
· 备选：也可以在「个人邮箱发信」里填一个个人邮箱的应用密码
  （Gmail 需先开两步验证后生成应用专用密码）测试发信；密码只经 DPAPI 加密保存在本机，
  不写日志、不回显、不用于其它用途。

【设置里都能调什么（v1.0.0）】
· 外观：主题（跟随系统/浅色/深色）、界面密度（紧凑/标准/宽松）、显示名称与副标题、
  列表加载条数（默认 20）、时间显示（相对 / 绝对）。
· 同步与通知：同步范围（全部历史 / 最近 N 封）、自动刷新间隔（秒，0 = 关闭）、
  启动时自动同步、新邮件自动 AI 总结 + Windows 通知、修复同步。
· AI 总结与问答：模型、DeepSeek API Key、问答引用条数（3-12）、批量总结、
  重新生成全部摘要、自定义总结提示词（可一键恢复默认）、检索索引覆盖。
· 发信：发信权限（SMTP.Send）、发送前二次确认、学校账号发信测试、发送能力自检、
  个人邮箱 SMTP（服务器/端口/TLS/账号/应用密码/测试收件人）。
· 关于与数据：打开邮件即本地已读（开关）、**附件保存位置**（留空 = 每次询问；可选目录/打开/恢复默认）、
  本地数据目录、隐私说明、恢复默认外观。

【已知限制（v1.0.0）】
· 发信目前只支持纯文本（不支持附件、富文本、HTML 签名）；
  发送时不会在服务器「已发送邮件」里留副本（Exchange Online 的 SMTP 提交行为），
  应用会在本地「已发送」记录一份，方便回看与排查。
· 归档/移动/删除仍不可用（只读设计）；草稿箱与已发送记录都只存本地。
· 未商业代码签名，首次运行需按上述方式放行。
· 若微软未发放可续期的 refresh 凭据，约 1 小时后需重新登录一次，
  应用会自动提示。

【数据与卸载】
· 数据位置：%APPDATA%\mail-ai-assistant\（邮件数据库、标签/视图/提醒/
  草稿、加密登录凭据、日志）。升级安装不会清空数据。
· 卸载：安装版用「设置 → 应用」卸载；便携版直接删除 exe。
  两者均可手动删除上述数据目录完成彻底清除。

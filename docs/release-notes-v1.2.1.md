自 v1.2.0 以来的全部更新合并为一次发版。

## 新增功能
- 5 套视觉风格可切换（Apple / Linear / Notion / 纸张 / 玻璃拟态，亮暗各一套），设置页即时预览
- 自绘标题栏（Windows 无边框窗口）：返回 / 全局搜索 / 全部已读 / 同步 / 设置 + 最小化/最大化/关闭
- 统一线性 SVG 图标（侧边栏 / 文件夹 / 详情工具栏 / 设置分区 / 窗口按钮）
- 拦截发件人（本地黑名单 + 折叠）：不进主列表、不计未读/角标、不弹通知，折叠到「已拦截」可随时恢复；不改服务器
- 待办改为备忘录式（手动增删、标题/正文/清单、引用邮件与自定义时间）
- 自定义 AI 模型入口 + 自动拉取服务商最新模型
- 一键已读、批量新邮件静默通知、开机自启、免打扰
- 本地 mock 模式运行真实 Electron（npm run dev:mock）

## 体验与修复
- 设置页按 Edge 分组列表重排：白色列表块 + 分组标题 + 扁平行，控件去边框，开关化，删纯说明行，长说明改行尾 ⓘ，新增设置搜索，保存按钮移到顶部
- 修复保存设置漏传 开机自启/免打扰/自动检查更新 导致勾选弹回；修复保存返回 undefined 报错
- 修复切换邮件「动画播完又跳一次」的双段跳转（去掉详情动画 + 新内容到达后滚动归零）
- 修复点开邮件列表跳回顶部、拦截后详情跳走、设置页空分区占位留白
- 修复 Windows exe 未写入品牌图标/版本信息（afterPack + rcedit）
- 修复单实例锁在 userData 不可写时静默退出；打包冒烟测试首次全绿
- 全站过渡动效，并移除 fixed 背景 / content-visibility / 主区毛玻璃等潜在重绘闪烁写法

# HHmail 排版架构候选（5 种完全不同的界面结构）

> 上一批是「同一种排版换 5 套配色」，这批是**换信息架构**：同样的邮件内容，但屏幕怎么分区、怎么读、怎么操作都不一样。
> 双击同目录 `.html` 可在浏览器里看；静态看 `.png`；先看 `compare-layouts.png` 总图。

| # | 排版 | 核心思路 | 适合 | 代价 / 不适合 |
|---|---|---|---|---|
| **L1** | **聊天式**（Twobird / Slack / 微信风） | 邮件按「会话」合并成消息流，左右气泡，底部输入框 | 跟导师/同学来回沟通多、想"像聊天一样回邮件" | 单封长邮件/通知类看着别扭；要按 thread 归并，改造量最大 |
| **L2** | **卡片流**（Feed / 社交风） | 无线索栏，单列大卡片，点开卡片内联展开正文 | 快速刷邮件、手机端思维、阅读舒服 | 邮件一多翻页累；没有列表密度；不像"专业邮件客户端" |
| **L3** | **看板**（Kanban / Trello 风） | 邮件按「待处理 / 等待回复 / 稍后 / 已归档」分列，拖拽改变状态 | 想拿邮箱当任务管理器、一眼看出"还欠谁" | 需要新增"邮件状态"概念；不适合纯浏览 |
| **L4** | **终端表格**（Bloomberg / mutt 风） | 深色高密度表格 + 右侧预览 + 快捷键 | 每天上百封、键盘流、极客 | 对普通用户太硬核；附件/图片体验弱 |
| **L5** | **仪表盘**（统计 + 邮件 + 待办一体） | 顶部 4 张统计卡，下面左右分栏：邮件列表 + 详情&待办 | 想一进来就看到"今天要干嘛"、和待办/日历打通 | 信息略多，小窗口会挤 |

## 我的建议
- 你是学校邮件 + AI 助手 + 待办，**L5 仪表盘**最贴合（把「未读/今天截止/待处理/待办」放第一屏）。
- 如果想要"轻快、现代"的差异化，**L1 聊天式**最有记忆点（但改造最大，且通知类邮件会怪）。
- 如果主要诉求是"高效处理"，**L4 终端**只有在你能接受全键盘/深色时才推荐。
- **L2 卡片流**更像消费类 App，不太建议做主线（可以作为"未读摘要"页）。
- **L3 看板**适合配合待办一起用（邮件→待办→看板流转），但纯邮件场景偏重。

## 排版 × 风格 可以自由组合
两批 demo 是独立的，你可以混着选，例如：
- 「**L5 仪表盘** + **风格 1 Apple**」= 干净、第一屏有统计；
- 「**L1 聊天式** + **风格 3 Notion**」= 温暖、像 Notion 里的消息；
- 「**L4 终端** + **风格 2 Linear**」= 深色高密度，最"专业工具"。

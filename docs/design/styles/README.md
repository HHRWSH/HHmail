# HHmail 视觉风格候选（5 套）

> 同一个界面（收件箱：侧边栏 + 邮件列表 + 详情），只换视觉风格，方便对比。
> 想交互的话直接双击同目录的 `.html` 用浏览器打开；静态效果看 `.png`。
> 先看 `compare.png` 总图，再点开单张看细节。

| # | 风格 | 一句话 | 适合 |
|---|---|---|---|
| 1 | **Apple 原生风** | 大面积留白 + 极细分割线 + 系统蓝 | 干净、耐看、最不容易出错（当前方向的精致版） |
| 2 | **Linear 深色工具风** | 近黑底 + 1px 发丝线 + 紫色点缀 + 键盘感 | 长时间盯屏幕、信息密度高、专业工具感 |
| 3 | **Notion 暖白极简风** | 米白底 + 衬线大标题 + 柔和软色块 | 温暖、像"第二大脑"，适合非工程师用户 |
| 4 | **纸张编辑风** | 暖纸色 + 衬线正文 + 印刷品式细线 | 阅读优先、像读论文/杂志，最有"质感" |
| 5 | **玻璃拟态（Arc 风）** | 渐变光晕 + 毛玻璃面板 + 大圆角 | 最"炫"，但长时间阅读/低配机器代价较大 |

## 参考来源（设计基准）
- **Apple HIG**：apple.com 产品页 / HIG 文档 —— 留白、`#1d1d1f` 墨色、`#f5f5f7` 软面、系统蓝 `#0071e3`、圆角 12–22、几乎无阴影。
- **Linear**：linear.app —— 暖近黑 `#08090a`、hairline `rgba(255,255,255,0.06)`、唯一强调色紫 `#5e6ad2`、圆角 ≤16、无彩色阴影。
- **Notion（pre-AI 时代）**：米白 `#f7f6f3` + 墨色 `#37352f` + 柔和色块（mint/peach/rose/sand）+ 友好衬线标题。
- **Stripe Press / 印刷品**：暖纸色、衬线正文、细分割线（第 4 套的灵感）。
- **Arc Browser**：渐变光晕 + 半透明毛玻璃面板（第 5 套的灵感）。

## 我的看法（仅供参考）
- 你要是想「稳、耐看、不折腾」→ **1 Apple 原生风**（也是现在代码里已经打好的基础，改造最小）。
- 想「专业、暗色爽」→ **2 Linear**（但 QQ 邮箱那种用户可能不习惯全黑）。
- 想「温暖、像记事本」→ **3 Notion**（配合我们刚做的备忘录式待办很搭）。
- 想「高级、像读书」→ **4 纸张风**（阅读长邮件最舒服，但工具感弱）。
- 想「炫、年轻」→ **5 玻璃拟态**（截图最好看，实际长期用可能累）。

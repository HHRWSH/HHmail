# HHmail 1.3.0 本地测试版 —— 测试清单

> 安装包在桌面 `HHmail 1.3.0 测试版` 文件夹里：
> - **HHmail-Setup-1.3.0.exe**（安装版，支持自动更新；建议用这个测）
> - **HHmail-1.3.0.exe**（便携版，免安装；自动更新不可用）
>
> 旧版本（1.2.0）可以直接覆盖安装；数据在 `%APPDATA%\mail-ai-assistant`，不会丢。

## 1. 待办（改版重点）
- [ ] 打开「待办」：**列表应该是空的**（旧版自动生成的任务会在升级时被清掉）——这正是本次要求的「自己添加」
- [ ] 点「＋ 新建待办」→ 右栏出现卡片：写标题、正文，**不用点保存**（等 1 秒），切走再切回来内容还在
- [ ] 输入清单项按回车 → 勾选/取消勾选 → 关掉再打开还在
- [ ] 「＋ 引用邮件」→ 搜一封邮件选中 → 引用区出现邮件卡片，点「打开 ›」能跳到原邮件
- [ ] 「＋ 引用时间」选一个时间 → 引用区多一条
- [ ] 截止时间、设为完成/标记未完成、删除（有二次确认）
- [ ] 筛选：今天 / 本周 / 全部 / 已完成；逾期显示红色
- [ ] 到「收件箱」打开一封邮件 → 点「☑ 加入待办」→ 待办里出现一条（带这封邮件引用）
- [ ] 邮件详情里 AI 摘要的「行动项」下方点「→ 待办」→ 变成待办卡

## 2. 一键已读
- [ ] 收件箱右上角「✓ 全部已读」→ 确认 → 未读消失，提示「已把 N 封邮件标记为已读」
- [ ] 打开服务器邮箱确认：**服务器上仍是未读**（我们只改本地，这是设计约束）

## 3. 自定义模型 / 自动拉取
- [ ] 设置 → AI 与标签 → 点「🔍 获取最新模型」→ 下拉出现服务商返回的模型列表（需已填 API Key）
- [ ] 下拉选「自定义模型…」→ 手填 `deepseek-v3.2`（或服务商新上的模型名）→ 保存 → 总结一封邮件，确认能正常调用
- [ ] 如果获取失败：应显示中文错误（不影响手填）

## 4. 新邮件过多静默通知
- [ ] 一次同步来 >5 封新邮件时，**不弹**系统通知（界面/未读数/角标照常变化）
- [ ] 少量新邮件（≤5 封）仍正常弹通知
- [ ] 用户自己点「同步」不弹通知（旧行为保持）

## 5. 开机自动启动
- [ ] 设置 → 关于与数据 → 勾「开机自动启动」→ 保存
- [ ] 注销/重启 Windows（或任务管理器确认启动项）→ 开机后应用**隐藏到托盘**，不弹窗口；点托盘图标能打开
- [ ] 取消勾选 → 启动项应被移除

## 6. 回归（确认没被改坏）
- [ ] 收信同步正常、列表能滚动加载更多
- [ ] 发一封带附件（中文名 PDF/JPG）的邮件
- [ ] 图片型邮件能正常显示图片
- [ ] 一键退订按钮（带 List-Unsubscribe 的广告邮件）
- [ ] 免打扰窗口内不弹通知

## 出问题怎么反馈
- 日志：`%APPDATA%\mail-ai-assistant\logs\app.log`（发我最后 200 行即可）
- 或者截图 + 描述操作步骤

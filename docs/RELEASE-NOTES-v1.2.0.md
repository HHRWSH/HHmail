# HHmail 1.2.0 —— 六项增强（发信附件 / 待办 / 免打扰 / 未读角标 / 一键退订 / 自动更新）

本版聚焦「把邮件客户端真正用得起来」的六件事，全部本地运行、收信仍然严格只读。

## ✨ 新增功能

### 1. 发信支持附件
- 发信弹层新增「📎 添加附件」：由**主进程**弹系统文件框并读取文件（渲染进程不直接读盘），支持移除与合计大小提示。
- 上限：最多 10 个、单文件 ≤15MB、合计 ≤20MB（超限给中文提示，不静默截断）。
- 邮件 MIME 使用 `multipart/mixed`：正文 base64 + 每个附件独立 part，**中文文件名按 RFC 2231 编码**（同时带 ASCII 回退名），base64 按 76 字符折行。
- 无附件时 MIME 与旧版逐字节一致，老收件端行为不变。
- 草稿暂不保存附件，界面会明确提示（不静默丢弃）。

### 2. 「待办」视图
- 自动把**索引卡片的 [DUE]** 与**摘要里的「## 截止与行动项」**汇成任务清单（零 AI 成本，纯规则解析）。
- 筛选：今天 / 本周 / 全部 / 已完成；逾期红色；点标题跳回原邮件；行内编辑标题与截止；手动新增/删除。
- 勾选完成会持久化，重建时保留（手动任务不会被覆盖）。

### 3. 免打扰
- 设置 → 免打扰：可设时间窗（支持跨午夜，如 23:00–08:00）。
- 窗内**不弹系统通知**，但照常同步、照常计入未读、界面照常刷新（只是"不打扰"，不是"不更新"）。

### 4. 未读角标
- Windows 任务栏角标 1–9 / 9+（图标运行时生成），托盘提示显示「品牌名 · N 封未读」；macOS 显示 dock 角标。
- 启动、后台同步、标记已读、手动同步后自动刷新，另有 60 秒兜底对齐。

### 5. 一键退订（List-Unsubscribe）
- 识别邮件头 `List-Unsubscribe` / `List-Unsubscribe-Post`（RFC 8058）：支持一键 POST、https 页面（打开浏览器完成）、mailto 发信三种方式。
- 安全约束：**只允许 https 与 mailto**（http/javascript/data/file 一律拒绝）、**必须二次确认**、渲染层不能传 URL、结果只记本地。
- 详情页显示「🚫 退订」，完成后变「✓ 已退订」。

### 6. 自动更新
- 安装版（NSIS）内置 electron-updater：启动 30 秒后自动检查（可关），也可手动「检查更新」；发现新版本由用户确认下载、显示进度、下载完成可「重启并安装」。
- 便携版（portable）不支持自动替换，会提示手动下载新版。
- 本构建未做代码签名，Windows 首次运行可能有 SmartScreen 提示（属正常现象）。

## 🔒 不变的底线

- 收信侧仍然**完全只读**：`SELECT` 只读打开、正文用 `BODY.PEEK[]`、不做 STORE/COPY/MOVE/DELETE，不会把服务器邮件标记为已读。
- 令牌只在本机用 Windows DPAPI（safeStorage）加密保存，不写日志、不回传渲染层。
- 渲染层只能通过 preload 白名单调用主进程能力。
